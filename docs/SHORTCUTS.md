# 단축어 연동 가이드

집중이 시작할 때와 끝날 때, macOS **단축어** 앱에 만들어 둔 단축어를 실행할 수 있습니다.
방해금지(집중 모드)를 켜고 끄기, 음악 재생·정지, 조명 바꾸기처럼 단축어로 할 수 있는 일은 무엇이든 됩니다.

## 설정 방법

1. 단축어 앱에서 단축어를 두 개 만듭니다. 방해금지를 예로 들면:
   - **방해금지 켜기** — "집중 모드 설정" 동작으로 방해금지를 "켬"
   - **방해금지 끄기** — "집중 모드 설정" 동작으로 방해금지를 "끔"
2. 메뉴 바의 뽀모도로 아이콘 → ⚙️(설정) → **단축어** 탭을 엽니다.
3. "집중을 시작할 때"와 "집중이 끝날 때"에 단축어의 **이름을 그대로** 적습니다. 비워 두면 실행하지 않습니다.
4. **실행해 보기**를 눌러 단축어가 실제로 도는지 확인합니다.

## 언제 실행되나

| 때 | 실행하는 단축어 |
|---|---|
| 집중이 시작될 때 (직접 시작, 휴식 뒤 자동 시작) | 시작 |
| 선택 화면에서 "10분 더 집중"을 골랐을 때 | 시작 |
| 집중 시간이 다 됐을 때 | 끝 |
| 집중 도중에 건너뛰기·초기화·앱 종료를 했을 때 | 끝 |

- 일시정지와 재개, 휴식이 시작될 때는 실행하지 않습니다. 휴식이 끝나(또는 휴식을 건너뛰어) 집중이 자동으로 시작되면 그것은 집중의 시작이므로 시작 단축어를 실행합니다.
- 집중 시간이 다 되면 끝 단축어를 먼저 실행하고, 그 뒤 선택 화면에서 "휴식 시작"을 골라도 다시 실행하지 않습니다.
- "전환 관리"를 꺼 두어도 집중의 시작과 끝에는 실행합니다.

## 동작 방식과 한계

- 앱은 `shortcuts://run-shortcut?name=<이름>` 주소를 열어 단축어를 실행합니다. 앱의 권한 설정은 바꾸지 않았습니다.
- 주소를 여는 것만으로 단축어 앱을 앞으로 가져오지는 않게 했습니다. 다만 단축어 앱이 스스로 창을 띄우는 것까지 막지는 못하고, 한 번 실행된 단축어 앱은 계속 떠 있습니다.
- 적어 둔 이름의 단축어가 없으면 단축어 앱이 오류를 보여 줍니다. 이름을 고치거나 칸을 비우세요.
- 단축어가 끝났는지, 성공했는지는 앱이 알 수 없습니다. 그래서 끝 단축어와 시작 단축어가 거의 동시에 요청되면(시간이 다 되자마자 "10분 더 집중"을 누르는 경우) 나중 것이 먼저 끝날 수 있습니다.
- 집중 도중에 앱을 종료하면, 끝 단축어의 실행 요청이 넘어갈 때까지 종료를 잠깐(최대 2초) 미룹니다.
- 앱이 강제 종료되거나 충돌하면 끝 단축어가 실행되지 않습니다. 방해금지를 켜 두었다면 켜진 채 남으니 직접 꺼야 합니다.
